## 공공·규제를 위한 문서 AI를, 기관의 서버 안에서

**klaro-hub**는 공공기관과 규제 산업의 문서를 이해하고, 근거를 인용해 답하고, 사람이 검토(Human-in-the-Loop)하도록 만드는 문서 AI 엔진입니다. 다른 문서 AI와 갈리는 지점은 성능 이전에 **배포 방식**입니다 — 문서를 클라우드로 내보내지 않고, 기관의 온프레미스·에어갭 환경 안에서 그대로 동작합니다.

### 왜 이렇게 시작했나

공공·금융·법무가 다루는 문서는 조직 밖으로 나가면 안 되는 것들입니다. 그래서 좋은 문서 AI가 나와도 정작 이들에게는 대체로 그림의 떡이었습니다. 우리는 순서를 뒤집었습니다 — **데이터가 기관을 떠나지 않는 것**을 먼저 정하고, 그 제약 안에서 실제 업무에 쓸 만한 정확도를 만드는 것. 그게 클라로가 푸는 문제입니다.

### 무엇을 만드나

- **klaro-hub** — 문서 수집·이해·검색·근거 인용·HITL을 갖춘 문서 AI 엔진
- **소버린 배포** — 온프레미스 / 에어갭 / 국내 인프라. 데이터 주권을 전제로 설계
- **에이전트 연동** — MCP·외부 API·SDK로 개방. 다른 시스템과 에이전트가 바로 붙여 씁니다

### 요즘 파고드는 것
