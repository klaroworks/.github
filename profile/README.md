## AI가 노동을 대신합니다. 결과는 사람이 검증하고 승인합니다.

주식회사 클라로는 **AI 노동 자동화 플랫폼**을 만듭니다. AI가 문서·데이터·코드 업무를 수행하고, 사람이 그 결과를 검증·승인한 뒤 업무에 반영합니다. 모든 산출물에 **근거**가 붙고, **승인** 이력이 남고, 전 과정이 **감사**됩니다 — 데이터가 조직 밖으로 나가면 안 되는 공공·금융을 위해 **온프레미스**에서 그대로 동작합니다.

### 두 제품, 하나의 신뢰 스택

**Klaro Hub — 지식노동 자동화**
공공·금융기관의 문서·데이터 업무를 수행하는 *Governed AI Engine*. 근거 기반 질의응답 · 장문 보고서 · 한글(HWPX) 네이티브 출력 · 검토·승인(HITL)을 온프레에서 통합 제공합니다.
교정형 RAG(CRAG)로 **답을 지어내지 않고**, vLLM·Ollama + LoRA 자체 서빙으로 **폐쇄망 단독 운영**됩니다.
› 운영 사례 — 서울시여성가족재단 **안심회계봇**(실서비스 운영 중), 서울AI재단 업무매뉴얼 Q&A

**Klaro Forge — 개발노동 자동화**
레거시 시스템 전환을 수행하는 *AI Delivery Control Plane*. 반영 전 컴파일·정적점검·SQL Diff·기준 입출력 비교로 근거를 만들고, TA·AA·QA·PM 승인 이력을 산출물과 함께 남깁니다.
› 검증 환경 — C·ECPG 2,000본+ 기간계 전환 픽스처. **소스가 외부로 나가지 않는 구조**.
